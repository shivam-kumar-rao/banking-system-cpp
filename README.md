# 🏦 Banking System (C++)

A console-based Banking System developed in C++ using Object-Oriented Programming principles.

---

## 📌 Features

- Create Customer Accounts
- Deposit Money
- Withdraw Money
- Transfer Funds
- Check Account Balance
- Transaction History
- Menu Driven Interface

- Object-Oriented Programming (OOP)
- Classes & Objects
- Vectors
- Functions
